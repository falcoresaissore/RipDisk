# DiskBurn 1.0.1 for macOS ARM64

DiskBurn is a native SwiftUI audio CD ripper derived from Asunder 3.0.1. It preserves CD extraction, GNUDB metadata lookup, track selection, progress controls, preferences, and WAV, MP3, Ogg Vorbis, FLAC, Opus, WavPack, Musepack, AAC and Monkey's Audio output.

## Download

Download the DMG and matching corresponding-source archive from the v1.0.1 release. The application is self-contained and does not require Homebrew on the destination Mac.

Requirements: Apple Silicon and macOS 27 or later. The build is ad-hoc signed rather than Apple Developer ID signed or notarized, so Gatekeeper may require Control-clicking the app and choosing Open.

## Source

The complete application source snapshot is available as `DiskBurn-1.0.1-app-source.zip` in this repository. Exact corresponding sources for every bundled backend are included in the matching release asset.
